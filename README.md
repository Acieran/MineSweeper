# Minesweeper - JavaFX Recreation

## Overview

This project is a faithful recreation of the classic Windows Minesweeper game, implemented using JavaFX for the graphical user interface (GUI). The goal was to replicate the original game's gameplay, difficulty levels, and overall user experience while adhering to object-oriented programming (OOP) principles.

## Features

*   **Classic Gameplay:** Replicates the gameplay of Windows Minesweeper, including:
    *   Generating minefields with varying difficulty.
    *   Handling left-click to reveal cells.
    *   Handling right-click to flag cells.
    *   Detecting mine explosions and game over conditions.
    *   Calculating the win condition.
*   **JavaFX GUI:** Utilizes JavaFX to create a modern and responsive graphical user interface.
*   **Difficulty Levels:** Offers the standard Minesweeper difficulty levels (Beginner, Intermediate, Expert).
*   **OOP Design:** Employs object-oriented principles (encapsulation, inheritance, polymorphism) for a well-structured, maintainable, and extensible codebase.

## Usage

*   **Left-click:** Reveals a cell.
*   **Right-click:** Flags or unflags a cell (marks a suspected mine).
*   **Game Over:** Occurs if you click on a mine.  The game reveals all mines.
*   **Win Condition:**  You win by revealing all safe cells without clicking a mine.
